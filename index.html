About this release

Version 1.0.0 supports documented scalar subsets. Physical PLC interoperability and protocol certification remain unverified. Runs as a local interactive application, not a Windows service. MQTT TLS/authentication and memory persistence are pending. The Windows packages are unsigned. See the included documentation for supported models, addresses, and limits.
